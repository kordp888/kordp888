## 제품 운영 원칙

- **Why first:** 기능 목록보다 해결할 문제와 반증 조건을 먼저 정합니다.
- **Accessibility by design:** 사용자가 기술에 맞추는 대신 기술이 사용자에게 맞춥니다.
- **Evidence in the loop:** 측정과 테스트를 배포 이후의 일이 아니라 제품의 일부로 설계합니다.
- **Human-gated AI:** 모델은 초안을 만들고 최종 판단은 사람이 내립니다.
